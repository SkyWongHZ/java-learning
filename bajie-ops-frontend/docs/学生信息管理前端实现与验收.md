# 学生信息管理前端实现与验收

> 文档版本：V1.0
> 编写日期：2026-07-26
> 前端项目：`bajie-ops-frontend`
> 后端项目：`springboot-demo`

## 1. 文档定位

本项目的主要学习目标是 Spring Boot 后端开发。前端不再单独编写完整产品需求文档，而是直接复用后端的需求、数据库和接口详细设计，以本文作为前端页面范围、交互约定和验收清单。

后端设计基线：

- `springboot-demo/docs/学生信息管理系统需求文档.md`
- `springboot-demo/docs/学生信息管理系统接口详细设计.md`
- `springboot-demo/docs/学生信息管理系统数据库设计.md`

## 2. 技术栈

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- Element Plus

- SCSS

沿用现有脚手架的布局、主题、统一请求封装和登录信息持久化方式，不引入新的状态管理或 UI 框架。

## 3. 页面范围

### 3.1 登录页

- 只保留账号密码登录。
- 登录接口：`POST /api/v1/auth/login`。
- 请求头固定携带 `system: 1`。
- 登录成功后保存 Token，并查询 `GET /api/v1/auth/me` 验证登录状态。
- 退出时调用 `POST /api/v1/auth/logout`，无论请求结果如何都清理本地登录信息。
- 不包含注册、修改密码、忘记密码和手机验证码登录。

### 3.2 学生管理

- 分页查询学生。
- 支持学号/姓名关键字、班级、课程筛选。
- 支持查看详情、新增、修改和删除。
- 新增和修改时，班级使用全量班级下拉框，课程使用全量课程多选框。
- 修改时学号只读；课程传空数组表示清空选课。
- 删除前二次确认。

### 3.3 课程管理

- 全量查询课程，支持编码/名称关键字搜索。
- 支持新增、修改和删除。
- 课程编码和名称均为必填项。
- 删除前二次确认；课程仍被学生选择时直接展示后端错误信息。

### 3.4 班级管理

- 全量查询班级，支持编码/名称关键字搜索。
- 支持新增、修改和删除。
- 班级编码和名称均为必填项。
- 删除前二次确认；班级下仍有学生时直接展示后端错误信息。

## 4. 路由与菜单

| 路由 | 菜单 | 默认入口 |
| --- | --- | --- |
| `/students` | 学生管理 | 是 |
| `/courses` | 课程管理 | 否 |
| `/classes` | 班级管理 | 否 |

原客户管理、设备档案页面及其业务代码全部删除，不提供兼容入口。

## 5. 接口约定

- API 根地址来自 `VITE_BASE_URL`。
- 请求统一携带 `system: 1`。
- 登录后的请求统一携带 `token`。
- 后端 `code = 1` 时返回 `data`。
- `code = 8` 或 `11` 时清理本地登录信息并跳转登录页。
- 其他业务失败直接展示后端 `msg`，不在前端复制业务错误码。
- 当前 Spring Boot 后端不使用前端 AES 协议，所有请求直接发送 JSON 或 Query 参数。

## 6. 页面交互约定

- 列表加载时显示局部 Loading。
- 提交按钮在请求期间禁用并显示 Loading。
- 新增或修改成功后关闭弹窗并刷新当前列表。
- 删除成功后刷新列表；学生当前页被删空时回到上一页。
- 表单前端只做必填、长度、手机号和枚举等基础校验，业务唯一性和关联有效性以服务端结果为准。
- 空数据展示 Element Plus 空状态，不伪造演示数据。

## 7. 验收清单

1. 未登录访问业务路由会跳转登录页。
2. 登录成功后默认进入学生管理。
3. 学生分页和三个筛选条件可正常组合使用。
4. 学生详情能展示班级与已选课程。
5. 新增学生能够选择一个班级和零到多门课程。
6. 修改学生不能修改学号，能够更换班级并完整替换课程。
7. 删除学生前有确认提示，成功后列表刷新。
8. 课程和班级列表不分页，支持关键字搜索。
9. 课程和班级均支持新增、修改、删除。
10. 被学生关联的课程或班级删除失败时展示后端具体提示。
11. Token 失效时自动清理登录状态并返回登录页。
12. `npm run type-check` 和 `npm run build:dev` 均通过。

## 8. 测试环境验收结果

2026年7月26日通过ECS测试环境完成真实浏览器验收：

- 未登录访问业务接口返回未登录状态，登录成功后进入学生管理。
- 新增班级、课程和学生成功，学生能够选择一个班级和一门课程。
- 学号/姓名、班级、课程三个条件组合筛选能够返回目标学生。
- 删除被学生关联的课程时显示“课程仍被学生选择，不能删除”。
- 删除包含学生的班级时显示“班级下仍有学生，不能删除”。
- 删除学生后页面刷新为空，随后课程和班级能够正常删除。
- 删除Redis会话模拟Token过期后，页面显示“登录已过期”并自动返回登录页。
- `npm run type-check`、`VITE_BASE_URL=/ npm run build:prod` 均通过。
- 页面联调业务数据、临时管理员和会话均已清理。

第一期前端验收清单全部通过。
